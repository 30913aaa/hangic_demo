遊び方

あなたは魔導士である。手にあるのは七枚の本源の種子——水・火・土・木・口・人・手。 それらを合成台に載せれば新たな漢字が生まれる。字はどれも一つの魔法であり、固有の階級と効果を持つ。 体験版では225種の字式を研究可能。完全版には2,892字を収録。

一、字を解き、組み直す

合成台には材料枠が四つある。カードを二〜四枚入れ、「合成」を押す—— 材料は最下層の種子まで解かれ、法則に従って組み直される。

木＋木＝林 木が二つで、林
木＋木＋木＝森 木が三つで、森

合成した字はそのまま新たな材料として使える。「森＋森」は木六つに等しい—— 材料枠は四つしかないため、高階の字を作る道はこれしかない。

二、結果は先に教えない

材料を置いても、画面は「初回観測待ち」としか示さない。合成を押して初めて明かされる。 これは意図的なものだ。この遊びの妙味は表を引くことではなく、自分の造字の勘を育てることにある。

試して結果の出なかった組み合わせは記録され、次に同じ材料を置くと「かつて共鳴せず」と示される。 失敗しても何も失わない。材料は台に残るので、一枚差し替えてすぐ試せる。

まずはこの2点だけ知れば始められます。ゲーム内には5ステップの操作ガイドがあり、法則や触媒は初めて実際に遭遇した時に説明されます。

法則・触媒・収集システムの全解説（後から読めます）

三、八条の法則が立ちはだかる

魔力は思いのままに組めるものではない。法則に反すると赤い表示が出て、 何条目に触れたか、どう解くかを直に告げる。

  • R1 階差律　材料どうしの階級差は 7 階を超えてはならない。
  • R2 極性律　水と火のように相剋する種子は打ち消し合うため、調和触媒を要する。
  • R3 潜在学派律　媒質触媒は術式に第三の学派を書き込む。
  • R4 四派超過律　材料が四学派にまたがると超過となり、概念学派の媒質。
  • R5 器皿律　Lv7 以上の魔力には容器触媒による担持が要る。
  • R6 錨点律　儀式には必ず種子字か純粋畳字を一枚、錨点として要する。
  • R7 学派排斥律　排斥し合う二学派が同時に現れると、空間学派の媒質。
  • R8 純粋律　同じ種子を重ねすぎると鎖されるため、破律触媒を要する。

法則は罰ではなく関門です。体験版ではR2／R3／R6／R7を実際に攻略でき、残りの枠は確保のみ——R1の大きな階差とR4／R5／R8の専用触媒は完全版で展開します。

四、四種の触媒

紫の儀式触媒枠種子字を一枚置き、先の法則を解くのに用いる：

調和R2 極性の対沖を解く
容器R5 高階の溢流を解く
媒質R4 を解く／R7、潜在学派を書き込む
破律R8 純粋の鎖死を解く

一つの種子が幾つもの役を兼ねうる。「龠」は容器・破律・調和・概念媒質の四資格を同時に備え、 多重の制限を単独で解ける唯一の本源である。

五、同底異字——この遊びで最も特異な機構

青の調律触媒枠法則を解かず、別のことをする： 同じ材料でも、調律触媒を変えればまったく違う字が生まれる。

木×4＝𣛧 調律を加えぬときの基準字
木×4＋糸＝𱤏 調律触媒「糸」を加える

体験版では14組、完全版では442組の分岐があります。調律ルートは直接公開されません—— 1 点の霊感霊感を費やして一つ読み解くか、自ら試し当てるかである。

六、霊感はどこから来るか

霊感は限りある研究補助の資源で、調律の道筋を読み解いたり手がかりを得るのに使う。 字の発見そのものでは霊感は得られない——霊感は三つの場所から来る：

  • 解放実績（各段階で +1）
  • 受け取る本源任務（各関門で +1）
  • 研究補給任務（カード面の表示による）

霊感が尽きても合成は自由に行える。補助がないだけである。

七、主線——四十九の本源を覚ます

初めは七枚の種子のみ。残る 42 枚は本源任務一つずつ覚ましてゆく。 各関門には明確な条件があります（指定の字を発見する、図鑑の収録数に達する、ある法則を解く⋯⋯）， 完了ののちは自ら自ら受け取る。主線は全 54 関門からなる。

本編は 15 章、700 のコア正典字と本源／法則の試練で構成されています。 エンディング後も 350 の正典選択字を埋めて、1,050 字の正典をすべて集められます。残る 1,842 字は界外の研究領域です。

八、実績と収集

体験版には達成可能な実績を82件収録。完全版では界外の銘印と長期収集目標も追加されます。 一部の実績は進捗に応じて進化する——たとえば「階序巡礼」は初昇から界外へと姿を変えてゆく。

操作方法

  • クリックカードは最初の空き材料枠に入る。また直接ドラッグ。
  • 右クリックどのカードでも完全な情報——構成・学派・読み・魔法効果——を見られる。
  • 左欄では検索——漢字・部件・ピンイン・注音のいずれでも入力できる。「口木」と入れれば、その二つの部件を共に含む字が見つかる。
  • キーボード：方向キーでカード格子を移動し、Enter で入れ、Esc で窓を閉じる。

何も暗記する必要はない。分からなければ右クリックで開き、法則に阻まれたらその赤い一行を読めばよい。 この遊びは、みずから教えてくれる。

クレジット

『漢字魔導錄』は多くの公開資料と自由ライセンスの資源の上に成り立つ。以下、ライセンス要件と寄与の度合いに従って挙げる。

字形

  • Jigmo（2025-09-12 版）—— 明朝体系のフォントで、CJK 拡張区を網羅する。 本作の 2,941 の卡面字はすべてオフラインで埋め込まれ、プレイヤーの環境フォントに依存しない。 ライセンス CC0 1.0。 公式ページ
  • Noto Serif TC／Noto Sans TC —— 界面の文字。ライセンス SIL Open Font License 1.1。

言語データ

  • Unicode Unihan Database —— 漢語ピンインの出典（kMandarin などの欄）。 注音符号はピンインから確定的な規則で変換した。ライセンス Unicode License。 公式ページ
  • Unicode IDS データ —— 漢字の部件分解の基礎であり、2,892 字の構成関係を導くのに用いた。

技術

  • ゲーム本体は単一の HTML ファイルで、フレームワークも外部依存もなく、オフラインで遊べる。
  • データ生成と検証の管線は Python 3.12 で書かれている。
  • クラウドセーブ（任意）は Firebase を使用します。ログインしなければすべてローカルで動作し、データは一切送信されません。

特記事項

ゲーム内の漢字はすべて実在する字か、IDS の規則に照らして構造的に成立する字です。架空の創作字ではありません。 魔法効果の叙述は本作オリジナルです。うち 517 条は手動で校閲済み、残りはプログラム生成の草稿で、今も修正を続けています。

字形・読み・データに誤りを見つけられた場合は、 issue を立てる またはメールで pimail307@gmail.com、ご連絡いただけると大変助かります。
